# Прокси Xray для Plasma 5

Компактный виджет показывает состояние пользовательской службы Xray, переключает готовые конфигурации и запускает или перезапускает службу. Он не меняет системный прокси и не преобразует профили Throne.

Проект создан для Plasma 5.27. Логика управления и QML проверены отдельно; работу виджета на панели в запущенной Plasma ещё нужно проверить.

## Перед установкой

Нужны Plasma 5, Python 3, Xray и пользовательский systemd. Виджет рассчитан на следующую схему:

- исполняемый файл Xray: `~/.local/share/xray-proxy/xray`;
- активная конфигурация: `~/.local/share/xray-proxy/primary.json`;
- готовые конфигурации: `~/.local/share/xray-proxy/profiles/*.json`;
- служба: `xray-proxy.service` запускает Xray с активной конфигурацией.

Каждая конфигурация для переключения должна содержать ровно один HTTP-вход на `127.0.0.1:20172`. Настройка исходящих соединений и, если нужны, файлов GeoIP/GeoSite остаётся за пользователем. Для SOCKS5 нужен отдельный SOCKS-сервер или реле: виджет их не создаёт.

**Не копируйте в репозиторий конфигурации с ключами и паролями.** Используйте только доверенные конфигурации: Xray запускает их от вашего имени. Каталог с конфигурациями должен быть доступен только владельцу (`0700`), файлы — только владельцу (`0600`).

## Установка

1. Создайте указанную структуру в домашнем каталоге, поместите туда исполняемый файл Xray и подготовленный конфиг. Сохраните конфиг как `primary.json` и как файл в `profiles/`. Не перезаписывайте свои существующие конфигурации.
2. Создайте `~/.config/systemd/user/xray-proxy.service`, указав существующий исполняемый файл и активный конфиг:

   ```ini
   [Unit]
   Description=Xray explicit HTTP proxy
   Wants=network-online.target
   After=network-online.target

   [Service]
   Type=simple
   ExecStart=%h/.local/share/xray-proxy/xray run -config %h/.local/share/xray-proxy/primary.json
   Restart=on-failure
   RestartSec=5
   UMask=0077

   [Install]
   WantedBy=default.target
   ```

3. Проверьте конфиг командой `~/.local/share/xray-proxy/xray run -test -config ~/.local/share/xray-proxy/primary.json`. Затем выполните `systemctl --user daemon-reload` и `systemctl --user enable --now xray-proxy.service`. Запуск без входа пользователя требует отдельно настроенного lingering в systemd.
4. Из каталога проекта установите помощник и пакет виджета:

   ```sh
   install -d -m 700 ~/.local/bin
   install -m 700 xray-widget ~/.local/bin/xray-widget
   kpackagetool5 --type Plasma/Applet --install package
   ```

5. Добавьте на панель виджет «Прокси Xray».

## Использование

Имя файла профиля без `.json` показывается в списке. Допустимы латинские буквы, цифры, `_` и `-`, не более 80 символов. При выборе помощник проверяет конфигурацию через Xray и перезапускает службу. При ошибке запуска он пытается восстановить предыдущую конфигурацию. Проверка синтаксиса не доказывает, что сервер доступен.

Индикатор показывает состояние процесса, а не доступность интернета. Если служба не запускается, проверьте `journalctl --user -u xray-proxy.service`. Журнал может содержать сетевые данные; проверьте его перед отправкой.

## Проверки

```sh
python3 -m unittest -v test_widget.py
```

Для изменений QML дополнительно нужны `qmllint` и проверка на панели Plasma 5.
